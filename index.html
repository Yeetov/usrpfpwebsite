Why UserPFP

Everything You Need

A lightweight, powerful solution for animated Discord profiles.

Animated GIFs

Use any GIF as your avatar. Submit via our Discord and it's hosted automatically on GitHub.

Dynamic API Images

Set a live API link — show a random cat, duck, or any image that refreshes over time.

Visible to Others

Your animated avatar shows up for all other UserPFP users across every supported client.

Client-Side Only

Works entirely client-side via CSS injection. No server mods, no account risk.

Get Started

How It Works

Step 01

Join the Community

Join the Official Discord Server to submit requests for animated PFPs or dynamic API links. Support is available there too.

Step 02

Submit Your Request

Upload your GIF or link in #request-here. If accepted, the bot hosts it automatically. Restart Discord after ~5 minutes to see it live.

Step 03

Install the Mod

Select your preferred client to view specific installation instructions.
